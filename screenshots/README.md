# Screenshots

Add your own screenshots of the running program to this folder before uploading to GitHub or submitting. Suggested files:

| File name | What to capture |
|-----------|-----------------|
| `01_menu.png` | The main menu after starting the program |
| `02_test_case_1_add_item.png` | Add Rice, 20, 60 → `Item added. ID: G101 ...` |
| `03_test_case_2_boundary.png` | Sell 5 of a quantity-5 item → `Out of stock` |
| `04_test_case_3_insufficient.png` | Sell 50 when stock is 20 → `Insufficient stock. Available: 20` |
| `05_test_case_4_sorted.png` | Option 3 – sorted display |
| `06_test_case_4_low_stock.png` | Option 4 – low-stock report |
| `07_persistence.png` | Restart the program and show the items are loaded again |
| `08_inventory_file.png` | The saved `inventory.txt` open in VS Code |

Tip: run `java -cp out Main` in the VS Code terminal from the project root, perform the steps above, and take screenshots (Windows: `Win + Shift + S`).
